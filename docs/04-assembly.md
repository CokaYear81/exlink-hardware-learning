# 04 · 最后的组装：把能运行的电路变成一台完整设备

## 本章起点

电路板焊接、固件烧录和上电测试都通过后，就来到最后的组装环节。这部分花的时间不算多，照着 [Exlink 成品组装与调试视频](https://www.bilibili.com/video/BV1vFUMBKEbN/) 的顺序，整体过程比较顺畅。这里主要记录我实际遇到的空间和适配问题。

## 组装流程

配套外壳的内部余量不大，正式固定前，我先把外壳、屏幕、电路板和电池试放一遍。电池与天线的位置比较紧，电池线太短会够不到供电点，太长又容易在壳内堆积、挡住螺丝孔，因此需要先想好走线方向。

| --- | --- |
| ![组装前的外壳与屏幕](../assets/04-assembly/shell.png) | ![电池在信号板背面的摆放](../assets/04-assembly/battery.png) |
| 图 1：先确认外壳内部空间和屏幕位置。 | 图 2：试放电池，检查板边、排针与导线的余量。 |

接着连接屏幕排线和两块电路板，再检查它们能否一起放进外壳。这次排针与 USB 接口的型号有些偏差，我临时剪短了排针较长的一端，并对 USB 接口突出的位置做了局部打磨，才让各部分合适地装在一起。

| 板间连接 | 侧面空间 |
| --- | --- |
| ![屏幕排线与两块电路板的连接](../assets/04-assembly/connect1.png) | ![连接后从侧面检查板间高度](../assets/04-assembly/connect2.png) |
| 图 3：合壳前确认排线和板间连接。 | 图 4：从侧面检查接口、排针和电池是否互相挤压。 |

最后整理好导线，确认它们没有压在壳体边缘或螺丝孔上，再合壳固定。组装后的设备能够正常点亮，先前分开的屏幕、电路板和外壳终于成了一台完整的工具。

## 阶段小结

到这里，整个复刻项目就进入尾声了。组装本身不复杂，却让我体会到外壳尺寸和内部走线也会影响成品效果。当时我还试着用 SolidWorks 修改外壳，但手头的 STL 是网格模型，直接按参数化零件的方式改结构并不顺手，最后选择用钳子和锉刀对打印件做局部修整。这次接触也让我发现建模值得继续学，以后有时间想再深入看看。
