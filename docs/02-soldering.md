## 相关工具

| 工具或材料 | 用途 |
| --- | --- |
| 电烙铁 | 固定元件、补焊、拖焊和局部返修 |
| 热风枪 | 同时加热一片区域，适合焊接或返修 QFN、Type-C 等器件；升温相对慢，但可以一次处理多个焊点 |
| 锡膏与焊锡丝 | 提供焊料；锡膏确实好用捏，自带助焊成分，配合热风枪很适合贴片焊接 |
| 助焊剂 | 改善焊锡的润湿和流动，拖焊、补焊以及处理连锡时都很有用 |
| 镊子与放大设备 | 放置、扶正元件，并检查连锡、虚焊和方向错误等问题 |
| 万用表 | 在上电前查短路，上电后确认各电源轨和信号状态 |
| 洗板水 | 清理电路板上的助焊剂、锡珠等残留 |
| 吸锡带 | 吸走焊盘或引脚上多余的焊锡 |

## 小封装！！！

0603、0402 封装、Type-C 接口和 QFN 芯片，对新手来说都有一定的焊接难度，非常考验手眼协调。眼睛要一直盯着那些 <sub><sub><sub>小小小小</sub></sub></sub> 的焊脚；没有固定架时（最好有一个），一只手还要设法稳住板子或元件，另一只手操作电烙铁和锡膏，整个过程中都得尽量保持稳定。
实际焊下来，感觉它确实有点磨人，也磨精神。

## 可能出现的问题及其解决办法

下面是我在焊接过程中遇到或重点排查过的几个问题：

| 现象 | 排查与处理 |
| --- | --- |
| 引脚连锡 | 先加助焊剂，再用干净的烙铁头沿引脚轻轻拖焊；如果焊锡仍然过多，可以使用吸锡带吸走多余的锡。 |
| 芯片虚焊 | 重点检查芯片引脚和底部焊盘是否真正吃锡。底部应使用适量锡膏并充分、均匀地加热，不能只看外侧引脚是否粘住。 |
| 上电测试时蜂鸣器持续鸣叫 | 检查 INA226 是否漏焊、虚焊，供电及 I²C 连接是否正常。现有固件在未识别到 INA226 时会持续重试，初始化无法继续。 |
| 屏幕只有背光、没有画面 | 优先检查 FPC 排线和座子是否接触良好。座子可能因热风温度过高而变形；确认损坏后，这边建议您直接换一个呢亲~ |

> [!CAUTION]
> 返修和通断检查前应先断开 USB、电池及其他电源。每完成一个阶段，先检查短路和焊点状态，再进行上电测试。

## 阶段小结

焊接并不是简单地把所有元件一次装完。按照功能分阶段焊接、检查和上电，虽然速度慢一些，但出现问题时更容易确定范围。这一阶段最大的变化，是我开始能够把上一章看到的原理图，一点点对应到手中的真实电路板上。
