# 00 · Preface: A New Starting Point for a Computer Science Student

[← Back to home](../README.en.md) · [Next: Learning to Read the Schematics →](01-schematic.en.md)

## Where I Started

As a second-year computer science student, I had worked mostly with code, algorithms, and other software topics before this project. Apart from some basic knowledge from high school, I knew almost nothing about hardware. I was a genuine beginner. Curious about how hardware works, I decided to build a replica of an existing project as the first step in learning it for myself.

## Why Exlink?

Exlink is an open-source project with fairly complete technical documentation, a bill of materials, and code. Building it seemed like a good way to connect the separate things I wanted to learn: schematics, components, soldering, and software. It was also challenging enough to make me discover problems, work through them, and grow in the process.

As AI has advanced, asking questions and finding information have become much easier. I could use AI to help answer questions that arose during the build, then deepen and check my understanding by reading source materials and working with the actual hardware. That made it possible to learn as I built.

## What I Wanted to Learn

The most immediate goal was, of course, to make a working Exlink. Beyond that, I wanted the hands-on work to help me answer four questions:

1. How can I understand a circuit board by reading its design files?
2. How do different components work in broad terms, and how should they be used?
3. How should I solder the boards, and what should I watch out for?
4. How do software and hardware work together?

Those questions became the thread running through this whole log. My first step was learning to read Exlink's schematics.
