# 图片素材说明

图片按章节存放：

```text
assets/
├─ 00-preface/
├─ 01-schematic/
├─ 02-soldering/
├─ 03-flashing/
├─ 04-assembly/
└─ 05-epilogue/
```

命名格式为 `章节编号-内容-序号.扩展名`，例如：

- `00-finished-exlink-01.jpg`
- `02-power-board-01.jpg`
- `03-esp32-flash-01.png`
- `04-before-closing-01.jpg`

建议优先使用适合网页展示的 JPG、PNG 或 WebP。添加图片后，应在对应章节补充中文替代文本和图注，说明图片展示的阶段、内容及记录价值。

第三方教程图片、固件、安装程序和整套资料不放入此目录。`01-schematic` 中现有截图来自 Exlink 开源原理图，仅作为个人读图记录使用，正文中已注明来源。
