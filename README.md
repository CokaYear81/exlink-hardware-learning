## 关于这份记录

我成功复刻了 Exlink，但这个仓库并不准备再写一份逐步操作教程。原作者和优化版教程已经把具体流程讲得很详细，我更想记录的是：一个原本主要和代码打交道的计算机专业学生，如何从看不懂原理图开始，逐渐理解电源、芯片、通信协议、焊接、烧录和整机调试。

这里会保留我的学习顺序、理解发生变化的时刻、遇到的问题，以及每个阶段留下的照片和截图。它首先是一份给自己的项目档案，也希望能让其他刚接触硬件的同学看到：第一次不懂很正常，复杂的板子也可以被拆成一个个能够理解和验证的小模块。

> [!NOTE]
> 这是一份个人复刻与学习记录，不是官方文档，也不能替代原项目的制作教程。涉及接线、焊接和通电操作时，请以原作者资料、器件数据手册及实际硬件情况为准。

## 从图纸到成品

```mermaid
flowchart LR
    A["看见 Exlink"] --> B["阅读原理图"]
    B --> C["认识器件与数据手册"]
    C --> D["分阶段焊接和测量"]
    D --> E["烧录三类固件"]
    E --> F["组装与整机测试"]
    F --> G["形成自己的硬件认知"]
```

这条路线看起来是线性的，但我的实际学习更像是在原理图、实物和程序之间反复往返：焊接时重新看原理图，烧录失败时检查硬件，程序报错时再回头理解芯片和通信总线。正是这些往返，让原本分散的知识慢慢连了起来。

## 我在这个项目里接触到的东西

这次复刻让我初步接触了原理图、数据手册、电源电路、常见通信方式、贴片焊接和固件烧录等内容。很多知识目前还停留在入门阶段，但在实际制作和排查问题的过程中，我开始尝试把程序、芯片与真实电路联系起来，也对一个硬件项目从图纸走向成品的过程有了更直观的认识。
